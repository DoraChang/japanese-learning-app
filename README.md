# 國高中智慧學習雲端平台 (Smart EdTech Taiwan) 核心系統架構與技術文件

本專案為一套專為臺灣國中與高中學子打造之**高安全性、極簡無干擾、遊戲化、具備家長監控、AI 拍照引導家教，以及「非強制性智慧考程與每日行程規劃」**的智慧學習平台核心程式碼。

後端採用 **Python (FastAPI + SQLAlchemy ORM)**，前端採用原生 **現代響應式 Single Page Application (SPA)**，支援「深色（Dark）」、「淺色（Light）」、「系統自訂（System Default，預設選項）」動態主題無縫切換。

---

## 🔒 核心安全與架構原則（絕對優先）

1. **零付費 / 無金流架構 (Zero-Payment Architecture)**：
   - 本平台為純公益、100% 免費之開放教育輔助系統。
   - 後端架構與程式碼中**嚴格杜絕並完全不包含任何信用卡、扣款、付費訂閱或第三方金流 API**（如 Stripe、PayPal、LinePay、綠界、藍新等）。
   - 伺服器中介軟體常駐注入 `X-Platform-Payment-Policy: ZERO_PAYMENT_FREE_PLATFORM` 宣告。

2. **嚴格資安防護與防提權（RBAC & Anti-IDOR/BOLA）**：
   - **身分角色垂直隔離**：區分學生 (`student`)、家長 (`parent`)、教師 (`teacher`)。非家長身分存取家長專用 API 直接回傳 `403 Forbidden`。
   - **防水平越權攻擊 (Anti-BOLA / IDOR)**：家長帳號**僅能存取與自身在資料庫建立合法關聯之未成年子女資料**。在所有家長查詢與指派作業 API，均通過 `verify_parent_child_relationship` 進行嚴格的外鍵複合檢核，杜絕任何猜測或竄改 ID 窺探他人子女隱私個資的可能。
   - **安全 Token 簽核**：使用純標準庫實作的 HS256 HMAC-SHA256 Token 簽名與時效驗證，具備抗計時攻擊 (`hmac.compare_digest`)，杜絕未經授權之偽造與篡改。

## 🌟 核心功能規格細節

### 1. 初始化與身分確認（Google 登錄）
- 支援個人 Google OAuth 2.0 登錄（內建本機開發模擬身分快速切換機制）。
- 首次登錄時，系統強制彈出**「身分選擇與年齡確認」精靈**（選擇學生、家長、教師並輸入年齡）。
- 若年齡未滿 18 歲，系統自動標記未成年保護機制，並生成專屬的 8 碼**「家長綁定代碼 (如 STU-8821)」**，以利家長快速添加與關懷。

### 2. 極簡、無干擾現代風格 (UI/UX)
- 視覺留白、聚焦學科題目的極簡卡片設計，排除任何花俏多餘的廣告或視覺干擾。
- 右上角常駐動態主題切換器：
  - **系統自訂 (System Default，預設選項)**：即時監聽作業系統 `prefers-color-scheme`。
  - **深色 (Dark)**：沉浸低眩光暗黑美學，夜間護眼。
  - **淺色 (Light)**：高對比純淨清爽風格。

### 3. 多維度動態學習選單
- **學制**：國中 (Junior High)、高中 (Senior High)。
- **年級**：國一 (七年級) ~ 國三 (九年級，會考衝刺)；高一 (十年級) ~ 高三 (十二年級，學測/分科)。
- **出版社聯動**：
  - 國中：康軒、南一、翰林。
  - 高中：龍騰、三民、泰宇、翰林、南一。
- **學科涵蓋**：國文、英文、數學 (數A/數B)、理化/自然、生物、地球科學、物理、化學、歷史、地理、公民。
- **題目標籤篩選**：支援 `#期中重點`、`#易混淆題`、`#挑戰題`、`#歷屆會考`、`#歷屆學測`、`#素養導向`。

### 4. 💡【選填功能】智慧考程與每日行程規劃引擎（非強制性）
- **彈性開關**：學生可依自身習慣自由選擇是否啟用。若關閉，即為無壓力之「自由自主刷題模式」。
- **參數輸入**：可設定段考名稱、目標段考日期、起始排程日與考試範圍。
- **排程演算法與緩衝**：
  - 自動依剩餘天數平均分派各科單元作業。
  - **自動保留考前衝刺與休息緩衝天數 (Buffer Days)**：考前 2~3 天不排新章節，專門保留給錯題本二刷與全真模擬。
  - **進度超前自動激勵 (Ahead Pacing)**：若學生進度超越預期進度 15% 以上，系統自動在今日行程中推薦「彈性超前預習單元」與「#挑戰題」徽章！

### 5. 遊戲化 10 級經驗值成長與連擊系統
- 前期快速升級提供即時成就感，後期指數階梯成長：
  - **Lv.1 學習萌芽** (0 ~ 60 EXP)
  - **Lv.2 知識求索者** (60 ~ 150 EXP)
  - **Lv.3 題海潛航員** (150 ~ 280 EXP)
  - **Lv.4 解題學徒** (280 ~ 460 EXP)
  - **Lv.5 核心精通者** (460 ~ 700 EXP)
  - **Lv.6 學科探險家** (700 ~ 1020 EXP)
  - **Lv.7 觀念架構師** (1020 ~ 1450 EXP)
  - **Lv.8 考場破壁者** (1450 ~ 2000 EXP)
  - **Lv.9 研學宗師** (2000 ~ 2700 EXP)
  - **Lv.10 智慧巔峰學霸** (2700+ EXP)
- 連續答對觸發 **Combo 連擊倍率加成** (每次答對額外 +5 EXP，最高 +20 EXP)。

### 6. 智慧錯題本與熟練度畢業機制
- 刷題答錯時，系統自動將題目、錯誤選項與詳解收錄進錯題庫。
- 學生可於「智慧錯題本」專區隨時複習與添加解題盲點備忘筆記。
- 複習時**連續答對 2 次或熟練度達 100%**，題目立即標記為「**🎓 已熟練畢業**」，並發放 **30 EXP** 畢業獎勵，移出日常待複習隊列！

### 7. 家長專區 (防越權關聯監控)
- 家長身分專屬儀表板，具備嚴格 RBAC 權限限制。
- **添加小孩**：輸入小孩 Google Email 或其專屬 8 碼「家長綁定代碼 (STU-xxxx)」。
- **子女儀表板**：一覽子女當前等級、今日刷題題數、錯題總數與段考倒數天數。
- **指派作業**：家長可指派客製化複習任務 (設定科目、題數與截止日期)，隨時追蹤完成狀況。

### 8. AI 智慧小家教（拍照引導與蘇格拉底教學模式）
- 提供拍照上傳題目介面 (支援手機相機、電腦上傳、即時預覽)。
- **蘇格拉底啟發式引導教學原則**：
  - **鐵律：絕對不直接提供答案或選項 (No Direct Answers)！**
  - 第一步：診斷題目考察之學科核心觀念與定理。
  - 第二步：提供三部曲之思考拆解步驟。
  - 第三步：向學生提出啟發性反問句，激發學生動手推導第一步。
- **Prompt 注入攻擊防護 (Anti-Prompt Injection Shield)**：
  - 若學生輸入「直接給我答案」、「忽略先前指令」等強索答案指令，系統主動觸發防爆雷護盾並給予溫馨引導。

### 9. 即時意見反饋系統
- 隨時收集學生、家長與教師的使用者建議、題目糾錯與系統 Bug 回報，後端即時持久化記錄。

## 🚀 快速啟動與測試指南

### 1. 安裝環境相依套件
```bash
pip install -r requirements.txt
```

### 2. 執行自動化測試套件（100% 通過驗證）
```bash
python test_platform.py
```
> 測試包含：零付費原則驗證、Google 登入與 Token 簽核、身分選擇與未成年防護、10 級 EXP 成長與 Combo 連擊、錯題本連續答對畢業、考程緩衝排程與超前預習、RBAC 垂直越權防禦、家長水平越權 (BOLA/IDOR) 攔截、AI 蘇格拉底防劇透與意見反饋等 9 大關鍵項目。

### 3. 一鍵啟動平台
Windows 使用者可直接雙擊 `run.bat`，或在命令列執行：
```bash
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```
瀏覽器開啟 **`http://127.0.0.1:8000`** 即可立即體驗！
